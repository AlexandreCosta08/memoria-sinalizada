# Memória Sinalizada: Jogo da Memória Bilíngue (Português/Libras)

> Projeto acadêmico desenvolvido para a disciplina/pesquisa com o objetivo de unir a lógica de programação web à acessibilidade e inclusão educacional infantil através de um jogo da memória interativo.

---

## 🚀 Sobre o Projeto
O **Memória Sinalizada** é um jogo da memória educativo voltado para o público infantil. A aplicação propõe uma abordagem bilíngue, onde a criança precisa associar o objeto do cotidiano (ex: itens de um quarto, parque ou escola) à respectiva representação do sinal correspondente em **Libras (Língua Brasileira de Sinais)**.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido utilizando tecnologias web fundamentais, garantindo leveza, alta compatibilidade e facilidade de execução:
* **HTML5:** Estruturação semântica das telas e componentes visuais.
* **CSS3:** Estilização responsiva, layout em Grid, design infantil amigável e animação de virada 3D (Flip).
* **JavaScript (ES6):** Lógica da aplicação, manipulação do DOM, controle de níveis, embaralhamento (Fisher-Yates) e validação dos pares.
